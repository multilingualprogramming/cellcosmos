Cellcosmos est un explorateur d'automates cellulaires élémentaires compilé en WASM depuis des sources multilingual françaises.

Le navigateur essaie d'utiliser `cellcosmos.wasm` pour accélérer le calcul, avec repli automatique sur JavaScript si besoin.
